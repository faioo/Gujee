# 区域地图构造题：给其他 AI 的四段思路

独立编程题描述，不依赖 Gujee 仓库实现细节。可用于让其他模型按同一题面解题与评测。

## 1. 问题描述

输入：标准输入单个整数 N（范围 8≤N≤10），表示棋盘边长。输出：标准输出一个二维数组（可写成 [[0,1,2],[1,1,2],...] 这种一行文本），外层与每个内层长度均为 N，元素为颜色编号 0 到 N-1，每种编号至少占一格；只输出这一个二维数组，禁止拆成多行矩阵或其它格式。若构造失败则输出为空（不打印任何内容）。时限：整次运行不超过 60 秒，超时判失败。题意：把棋盘涂成 N 种颜色。同色格子必须上下左右连成一整块，不能断开；其中至少有一种颜色只占 1 格。在棋盘上放棋子：每一行、每一列、每一种颜色各放恰好 1 枚，任意两枚不能挨着（上下左右和斜对角都不行）。满足这些规则的放法必须恰好只有一种。

## 2. 测试思路

评测限时 60 秒运行程序并读标准输出。超时或输出为空直接失败。否则把输出解析为二维数组，要求恰好 N×N（N 在 8..10），元素为整数 0..N-1 且每个编号都出现。再检查：同色是否上下左右连成一块、是否存在只占 1 格的颜色、按放棋规则统计合法方案数（数到 2 即停）是否恰好为 1。任一项不符即失败。

## 3. 参考解思路

做法参考：先随便找出一组合法的放棋位置当作种子（每行每列各一枚，且互不挨着）。再以这些格子为起点，把颜色区朝上下左右扩张，直到铺满棋盘，形成 N 块。若没有「只占一格」的颜色，就从某块边缘裁格子给邻居，挤出单格。若发现第二种合法放法，就微调相邻颜色的边界，把多余解毁掉，再复查，直到只剩一种解。最后把结果作为二维数组输出（一行文本即可）；失败则什么都不输出。总耗时须压在 60 秒内。

## 4. 环境思路

推荐使用 Python 3 完成解题与评测。棋盘用二维数组存储，构造、连通检查、搜解放法、调整边界都比较直观；成功时把二维数组 print 成一行文本，失败则不输出。评测脚本同样用 Python：subprocess 限时 60 秒运行选手程序，读取 stdout，用 ast.literal_eval 解析二维数组，再做连通与唯一解校验。仅使用标准库即可，无需安装第三方包。
