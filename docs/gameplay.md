# 玩法说明

## 规则

1. 棋盘分成若干彩色区域；尺寸为 N×N 时共有 N 个区域。
2. **每行、每列、每个彩色区域**恰好放置 **1** 只咕叽。
3. 任意两只咕叽**不能相邻**（上下左右与斜对角都不行）。
4. 点击格子循环：空 → ×（排除）→ 咕叽 → 空。

## 教学三关

| 关卡 | 教什么 |
|------|--------|
| 教学 1 | 放置咕叽；单格区域必放 |
| 教学 2 | 用 × 标记不可能格 |
| 教学 3 | 相邻（含对角）禁止 |

教学页可随时「跳过教学」。首页可「重玩教学」。

## 正式关

- 入门 5×5、进阶 6×6、挑战 7×7～8×8
- 工具：撤销、清空、提示（高亮一个强制格）
