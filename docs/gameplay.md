# 玩法说明

## 规则

1. 棋盘分成若干彩色区域；尺寸为 N×N 时共有 N 个区域。
2. **每行、每列、每个彩色区域**恰好放置 **1** 只咕叽。
3. 任意两只咕叽**不能相邻**（上下左右与斜对角都不行）。
4. 点击格子循环：空 → ×（排除）→ 咕叽 → 空。
5. **长按并拖动**可连续标 ×，快速排除。长按后需滑到其他格子才会标 ×；按住不移动再松开则无操作。
6. **自动清死格**可在首页设置中开启（放置后自动标记不可能的格子）。默认关闭。
7. **色弱模式**可在首页开启：棋盘使用高对比色板，并叠加区域小图案与编号，不单靠色相分区。

每关都有**唯一解**，开局至少有一个**单格色块**作为入手线索，且**同色格子连成一块**（四连通，无飞地）。

## 教学三关（均为 4×4）

| 关卡 | 教什么 |
|------|--------|
| 教学 1 | 放置咕叽；单格色块必放 |
| 教学 2 | 用 × 标记不可能格 |
| 教学 3 | 相邻（含对角）禁止 |

教学页可随时「跳过教学」。首页可「重玩教学」。

## 正式关

- 入门 5×5、进阶 6×6、挑战 7×7～8×8
- 后续关卡可能做到约 10×10
- 工具：撤销、清空、提示（高亮一个强制格）
